# 泰康 PPT 模板要求

本文件根据 `泰康保险集团PPT主题模板要求v1.pptx` 提炼。实际制作 PPT 时，以 `../assets/taikang-ppt-template.pptx` 为模板文件。

## 模板定位

- v1：规则来源。
- v2：制作新 PPT 的直接模板。
- v3：内容页排版参考。字体大小，字体和颜色以内容页字体层级要求为准。

新 PPT 必须从 v2 模板复制生成，不得用空白 PPT 仿制。

## 封面

- 保留 v2 封面背景、Logo、装饰色块和文本框结构。
- 只替换报告标题、二级标题、汇报人、汇报时间。
- 报告标题：微软雅黑（标题），加粗，44pt。
- 二级标题：微软雅黑（标题），加粗，28pt。
- 汇报人和汇报时间：微软雅黑 Light，18pt，加粗。
- 报告标题和二级标题各自保持一行显示。

## 目录

- 目录保持一页。
- 使用 v2 模板目录页样式。
- 保持目录编号、文字、线条和位置风格。
- 不得出现重复标题、重影或多套目录编号。

## 内容页字体层级

- 一级文字：幻灯片主标题，微软雅黑 / 微软雅黑标题，28pt，加粗。
- 二级文字：幻灯片副标题，微软雅黑，20pt，加粗，按模板需要使用字体阴影。
- 三级文字：观点性正文，微软雅黑，18pt，加粗。
- 四级文字：一般正文、图表主标题，楷体，16pt；突出部分可加粗或标橙；行距约 1.2-1.5 倍。
- 五级文字：图表副标题、图表数据，楷体，14pt；数据可用微软雅黑 14-16pt；突出部分可加粗。
- 六级文字：图注、底注，楷体，10-12pt。

下级文字字号原则上不得大于上级文字。各级文本框必须对齐清楚。

## 标准色

v1 标准色卡包括：

- RGB 238/120/0。
- RGB 255/173/92。
- RGB 255/228/201。
- RGB 217/217/217。
- RGB 191/191/191。

橙色用于重点观点、关键数据和结构强调，不应大面积滥用。

## 内容页固定元素

- 使用 v2 模板内容页版式。
- 保留标题区、Logo、标题下划线、页码、页码下划线。
- 一级主标题只能一行显示，只能替换模板原有标题文本框内文字；不得新建、移动、重画或换行。
- 二级副标题只能一行显示，只能替换模板原有副标题文本框内文字；不得新建、移动、重画或换行。
- 标题不得碰撞 Logo。
- 正文内容不得遮挡标题下划线、页码和页脚。
- 正文主体应整体放入安全区并水平居中。

## v1 第 4 页正文样式

- 观点性正文标题可使用橙色三级文字，居中或位于内容组上方，例如“三级文字，这是观点性正文1/2/3”。
- 列表标号与正文文字应清楚分离并对齐，避免序号压字。
- 可使用左侧竖排橙色方块图标作为大段正文的视觉标号；图标内可放白色线性符号或简化图形。
- 可使用橙色小圆点作为分项标号，文字使用四级正文；突出词可加粗或标橙。
- 可使用黑色实心方块作为卡片内一级项目标号，下方用黑色圆点列出子项。
- 可使用黑色圆点作为常规项目符号，适合普通正文列表。
- 多列列表可放在浅灰底色块内，色块无重边框，列与列之间留出清晰间距。
- 同一页的标号样式应统一；需要表达层级时，优先用“橙色图标/方块 + 圆点列表”或“黑色方块 + 黑色圆点”组合。

## v1 第 4 页表格样式

- 表格不使用完整外框，不画竖线。
- 用橙色细横线表现表格结构：表格标题下横线、表头下横线、底部横线。
- 图表主标题使用橙色，位于表格左上方或上方；标题文本按四级文字处理。
- 表头加粗、居中。
- 表格正文以楷体为主，居中排布。
- 重点行或汇总行可加粗。
- 表格左右边缘与正文安全区对齐，表格宽度根据内容留出呼吸感，不贴边。

## 专业图表五要素

- 图表主标题：表达图表观点。
- 图表副标题：概述图表内容。
- 图表主体：图表类型合理，配色重点突出。
- 图表元素：坐标轴、图例、数据标签、单位、刻度和含义。
- 图表备注：数据来源和必要附注。

图表过密时，拆页或重排，不通过压缩字号解决。

## 检查标准

- 封面、目录、内容页和结束页均保留 v2 模板结构。
- 内容页一级主标题和二级副标题均使用模板原框文字替换，且各自一行显示。
- 内容页标题下划线显示正常。
- 页码和页码下划线显示正常。
- 文字不溢出、不裁切、不贴边、不遮挡。
- 序号、项目符号、连接线、图表、表格和说明文字之间留有清晰间距。
- 表格无外框时，橙色横线、表头、数据和重点行必须清晰可读。
- 渲染后逐页检查，发现问题必须修改后再交付。优先使用 Microsoft PowerPoint 导出 PDF 或预览图；PowerPoint 不可用时，再使用 LibreOffice 兜底。WPS 只作为人工打开复核选项，不作为自动化导出检查工具。
