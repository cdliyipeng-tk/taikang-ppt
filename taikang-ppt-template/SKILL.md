# 泰康 PPT Skill

## 唯一资料体系

本 skill 只按用户指定的三份资料工作：

- `泰康保险集团PPT主题模板要求v1.pptx`：模板要求与检查标准来源。
- `assets/taikang-ppt-template.pptx`：制作新 PPT 时直接使用的模板，来自 `泰康保险集团PPT主题模板v2.pptx`。
- `assets/content-layout-reference.pptx`：内容页排版参考，来自 `泰康保险集团PPT内容页排版布局示例v3.pptx`。

制作泰康 PPT 时，必须从 `assets/taikang-ppt-template.pptx` 复制生成工作文件，再根据资料添加内容。不得新建空白 PPT 后仿制模板。

`assets/content-layout-reference.pptx` 只用于内容页正文区域的排版参考，包括文字的大小，字体和颜色，图表、表格、流程图、图文组合、数据表达和页面密度。它不作为新 PPT 的母版文件。

## 必读资料

开始制作、修改或审核泰康 PPT 前：

1. 读取 `references/style-guidelines.md`。
2. 如涉及内容页设计，读取 `references/middle-content-reference.md`。
3. 检查 `assets/taikang-ppt-template.pptx` 的实际母版、版式、占位符、Logo、页码、标题下划线和结束页。
4. 需要内容页排版灵感时，再检查 `assets/content-layout-reference.pptx`。

## 制作规则

- 封面、目录、内容页、结束页都以 v2 模板为准。
- 保留 v2 模板的母版、版式、主题、字体、颜色、Logo、标题区、页码、页码下划线和结束页样式。
- 封面只替换文字内容，不重建封面文本框。
- 目录保持一页，根据内容调整目录项。
- 内容页使用 v2 模板中的“标题和内容”等合适版式生成。
- 内容页一级主标题只能一行，二级副标题只能一行；两者都只能在模板原有文本框内做文字替换，不得新建文本框、移动位置、改版式或让文字换行。
- 内容页标题、Logo、标题下划线、页码和页脚区域不得被正文内容遮挡。
- 正文内容应放在安全区内，整体居中，左右留白均衡。
- v1 第 4 页正文样式要作为内容页参考：观点性正文上方可用橙色三级标题；正文列表可使用左侧橙色方块图标标号、橙色小圆点、黑色方块或黑色圆点标号，标号与文字分离并对齐。
- v1 第 4 页表格样式要作为表格参考：表格不使用外框，主要用橙色细横线区分表头、主体和底线；表头加粗居中，数据区居中，重点行可加粗。
- 图表、表格、流程图和说明文字应保持可编辑，除非用户明确要求使用图片。
- 高影响视觉可优先使用 GPT Image 2 风格图片生成，例如封面、章节页、概念场景和关键视觉；图表、表格和文字密集页保持清晰、可编辑。

## 字体层级

按 v1 模板要求使用以下层级：

- 一级文字：幻灯片主标题，微软雅黑 / 微软雅黑标题，28pt，加粗。
- 二级文字：幻灯片副标题，微软雅黑，20pt，加粗，按模板需要使用字体阴影。
- 三级文字：观点性正文，微软雅黑，18pt，加粗。
- 四级文字：一般正文、图表主标题，楷体，16pt；突出部分可加粗或标橙；行距约 1.2-1.5 倍。
- 五级文字：图表副标题、图表数据，楷体，14pt；数据可用微软雅黑 14-16pt；突出部分可加粗。
- 六级文字：图注、底注，楷体，10-12pt。

下级文字字号原则上不得大于上级文字。所有文本框必须对齐清楚，不得溢出、裁切、贴边或遮挡。

## 图表要求

专业图表按 v1 的“五要素”组织：

- 图表主标题：说明图表表达的核心观点。
- 图表副标题：说明图表展示的内容。
- 图表主体：选择合理图表类型，重点突出且易于区分。
- 图表元素：坐标轴、图例、数据标签、单位、刻度和含义。
- 图表备注：数据来源和附注。

数据复杂时，先清洗、汇总和校验数据，再设计图表。

## 交付检查

交付前必须渲染并逐页检查。优先使用 Microsoft PowerPoint 导出 PDF 或预览图；PowerPoint 不可用时，再使用 LibreOffice 兜底。WPS 只作为人工打开复核选项，不作为自动化导出检查工具：

- 封面文字位置、大小、样式与 v2 模板一致。
- 目录只有一页，无重复标题或重影。
- 内容页标题一行显示，不碰 Logo。
- 内容页一级主标题、二级副标题均为模板原框文字替换，且均未换行。
- 内容页标题下划线、页码、页码下划线显示正常。
- 正文内容未侵入标题区、Logo 区、页码区和页脚区。
- 表格、图表、序号、说明文字之间无重叠。
- 文字无溢出、裁切、隐藏尾字。

最终交付 PPTX，并在回复中说明文件路径。展示预览图时，先复制到 ASCII 路径，例如 `/tmp/codex_preview/taikang_contact_sheet.png`，再用 Markdown 图片语法嵌入。
